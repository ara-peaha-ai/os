description: Use for responsive layouts, mobile behavior, breakpoints, accessibility, tooltips, and polished UI details.
---

Design desktop, tablet, and mobile behavior.
Use fluid sizing with `clamp()`, percentages, and aspect-ratio.
Avoid rigid fixed-pixel layouts unless necessary.
Keep touch targets usable on mobile.
Add accessible labels for interactive elements.
Make hover tooltips degrade gracefully on touch screens.
Reduce visual density on small screens.
Avoid layout shifts and unnecessary JavaScript.
